# 文字提取与校对

交付用户指定范围内忠实、可复用的文字。用户明确的范围、格式和校对要求优先。

处理视频链接、本地音视频或字幕文件时，读取 [自动转写与核对流程](references/video-subtitles.md)。图片和 PDF 任务无需读取该文件；下文的页码、题号等要求仅适用于对应材料。

## 先复用，再提取

- 优先查找当前对话已给出的转写、明确关联的文件或用户指定的记录；必要时只搜索相关材料目录，不为找缓存遍历整个磁盘。
- 确认已有转写对应同一来源及页码或时间范围。完整且无新疑点时直接复用；有修改、缺失或争议时只补提或核对相关部分。用户要求重新识别或完整校对时按其要求执行。
- PDF 有可用文本层时先直接抽取；图片和扫描页使用当前可用的图像识别或 OCR。混合 PDF 按页选择。只有阅读顺序、表格、公式或识别结果存疑时才额外查看相关页或局部。

## 保留原文，标明疑处

- 保留标题、段落顺序、页码、题号、全部选项和有意义的空白；公式保留上下标、正负号，表格保留行列对应。可清理排版造成的断行，不擅自改写、摘要或补全原文。
- 无法确定的字用 `[不清楚]`；候选读法放在独立校对说明中。原文有错字、题号冲突或数量不符时保留原样并注明，不依据题意猜补公式或答案。
- 转写题目与解答分开。用户同时要求解题时，先取得可靠题干，再独立推导；选项、判断题陈述和旧转写均不视为答案依据。
- 检查指定范围是否完整、阅读顺序是否正确，以及题号、选项、公式和表格是否遗漏；对疑处回看对应局部，不无故重复识别已核实的整份材料。

## 保存以便下次使用

- 短文本可直接回帖。较长材料默认将完整转写保存为 UTF-8 Markdown 到当前任务允许的交付目录，名称采用原文件名加 `_文字转写.md`；用户指定其他格式或只要聊天文本时照办。
- 文件注明来源、覆盖页码或时间范围及尚未确认的位置。正文和校对说明分开，不把画面描述混入原文；不覆盖用户的原文件或已确认转写，修订时另存或按明确要求更新。
- 回帖给出文件链接与必要的疑点说明，避免再次粘贴整份长文。后续问题优先检索这份文字，仅在内容有争议时返回原图或原音视频。
